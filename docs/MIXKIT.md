# Mixkit — manual video library (no scraping)

Mixkit has HD/4K stock footage but no documented public search/download API. Its terms prohibit scripts/bots mass-downloading items. Do NOT scrape Mixkit pages, discover hidden download endpoints, or run an automatic Mixkit crawler.

1. Open https://mixkit.co/free-stock-video/ and select a genuine moving video (not an image or AI still).
2. Check the individual clip's license: **Mixkit Stock Video Free License** for commercial/social-media use; **Restricted License** is not suitable for monetized projects.
3. Download manually through the website. Prefer 1080p/4K originals and verify the clip matches the script.
4. Keep a local record of clip URL, author if shown, license and date. Do not commit video binaries to a public repo without checking distribution rights.

**Integration status:** manual discovery only. Mixkit is NOT in the automated Purffle provider list and is not counted as a working API source. Existing Pixabay, Coverr, Wikimedia and NASA searches are unchanged. An official Mixkit API or explicit permission would be needed for automated acquisition.
